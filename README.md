Адаптация звуковой энтропии под системы MACOS, принцип тот-же: 
 1. Считываем сырые сэмплы* (тут очень много веселья с библиотекой AudioToolbox, оно в capture())
 2. Выделяем n последних бит каждого сэмпла (самые рандомные, принято брать 1-2 бита)
 3. Объединение этих бит в байты (фактически просто сжатие для ускорения последующей обработки)
 4. Хэширование по SHA-256
