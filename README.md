Суть работы: 
 1. Считываем сырые сэмплы* (тут очень много веселья с библиотекой winmm, оно в capture())
 2. Выделяем n последних бит каждого сэмпла
 3. Объединение этих бит в байты
 4. Хэширование по SHA-256

Пояснения по функциям:
 1. winmm.lib требует выделение памяти в куче через GlobalAlloc, 
    так как при использовании malloc/new могут возникнуть непредсказумые ошибки
    из-за устаревшей winmm.lib, ожидающей HGLOBAL структуры

Пояснения по типам данных/константам:
 - DWORD = unsigned long (from windows.h; используется в WinAPI для времени, например, для GetTickCount)
 - HWAVEIN = дескриптор (handle), указатель на структуру для волнового входа, типо как FILE (from mmsystem.h)
 - MMRESULT = код ошибок в windows.h
 - MMSYSERR_NOERROR = const 0 (из windows.h, означает отсутсвие ошибок)
 - WAVEFORMATEX = struct (from winmm.lib, задает параметры получаемого звука)
 - WAVE_MAPPER = утсройство по умолчанию в Windows
 - WAVEHDR = структура-обертка, описывающая буфер, требуется для  waveIn (флаги и другая чепухня, просто требуется)
 - LPBYTE = указатель на структуру BYTE (буфер драйвера - массив байт)
